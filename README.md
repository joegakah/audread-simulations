# Virtual Science Simulations

Interactive HTML-based simulations for exploring scientific concepts through hands-on virtual experiments.

## 🚀 Quick Start

1. Clone the repository
```bash
git clone https://github.com/joegakah/audread-simulations.git
```
2. Start experimenting!

## 📋 Featured Simulations

- **Physics**: Projectile motion, pendulum dynamics, wave interference
- **Chemistry**: Atomic orbitals, pH simulations, reaction kinetics
- **Biology**: Population growth models, DNA replication
- **Astronomy**: Solar system orbits, gravitational fields

## 🛠️ Technologies

- Vanilla HTML5 / CSS3 / JavaScript
- Canvas API for rendering
- Responsive design for all devices
- No external dependencies

## 🎮 How to Use

1. Navigate to any simulation from the main menu
2. Use interactive controls to adjust parameters
3. Observe real-time changes and data visualizations
4. Reset or export results as needed

## 📱 Demo

Live demo: [https://joegakah.github.io/audread-science-simulations](https://joegakah.github.io/audread-science-simulations)

## 🆕 Adding New Simulations

```
src/
├── simulations/
│   └── simulation.html
└── assets/
```

1. Create new folder in `src/simulations/`
2. Add your HTML, JS, and CSS files
3. Register in `index.html` menu
4. Submit pull request!
